# MediaDiscover

A static movie/TV discovery landing page built with HTML, CSS, and JavaScript.

## Overview

A front-end assignment project presenting a "media discovery" style landing page with sections for trending movies and TV shows, plus FAQ, privacy, and terms pages.

## Features

- Home / hero section
- Trending movies and TV shows sections
- FAQ, Privacy Policy, and Terms pages

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```text
MediaDiscover/
├── index.html
├── faq.html
├── privacy.html
├── terms.html
├── index.css
├── Images/
└── SVGs/
```

## Installation

```bash
git clone <repository-url>
cd MediaDiscover
```

Open `index.html` in a browser.

## Learning / Purpose

An assignment project demonstrating static, multi-page front-end layout and styling with HTML/CSS.
